# 103 Arcade Game Hub — Playability Audit (2026-10-16)

Scope: all eight game pages in `docs/`, the hub (`docs/index.html`), and the AI coach API
(`api/`). Method: full code read of the hub + FlipMatch, structural review of the three
engine games and their content files, live checks of every page and `/api/health` on
https://103-arcade-game-hub.vercel.app/ (all 200; AI coach reports `aiConfigured: true`,
model gpt-4o-mini).

## Verdict in one line

The three "engine" games are real learning games with deep progression systems. The hub
only counts those three — the five standalone games are playable but invisible to hub
progression, which is the main reason the hub feels hollow ("0 / 500 XP" forever for
anyone playing the small games).

## The engine trio — REAL (WordQuest / SpellBuzz / NumBuzz)

Each runs a ~950-line engine over a large content file (705–1,430 lines) with:

- Per-game persistent profiles (`wordquest_profile`, `spellbuzz_profile`, `numbuzz_profile`)
- Per-skill mastery tracking, accuracy, weakest-skill targeting, play history
- Grade bands (preschool–7th grade), placement quiz, parent panel with PIN
- World maps with nodes, unlock requirements, region gating, weekly challenges
- Rewards in the hub's economy: lessons pay 15–25 XP + 1 star
- Boss mode (NumBuzz), rewards/unlocks, export/import of profiles

The hub aggregates XP, stars, and companions across exactly these three profiles
(500 XP per level).

Weaknesses: progress is localStorage-only (no accounts, no cross-device), presentation
is card/lesson-first rather than arcade-action, and the engine exists as three forked
copies (~950 lines × 3) — a maintenance risk if one gets a fix the others don't.

## The standalone five — PLAYABLE BUT DISCONNECTED

| Game | Lines | Loop | Hub XP |
| --- | --- | --- | --- |
| AbcBuzz | 577 | Timed letter/word rounds, own leaderboard | No |
| FlipMatch | 225 | Memory match: 4/6/9 pairs, lives, timer, streaks, leaderboard | No |
| SentenceQuest | 584 | Sentence-building rounds, own scoring | No |
| PatternPop | 140 | Pattern rounds — thin | No |
| RhymeTime | 159 | Rhyme rounds — thin | No |

None of them writes a profile the hub reads, so none of their play moves the hub's
level bar, stars, or totals. Each also keeps its own mute/leaderboard keys.

## AI coach — REAL and live

`api/coach.js` + `api/hint.js` call OpenAI (gpt-4o-mini) with kid-safe subject prompts
(never reveals answers; strategy hints only). Key-gated with a graceful off state;
`/api/health` confirms it is configured in production. Shared client: `arcade-ai.js`.

## The fix plan

1. **Standalone → hub profile contract (this pass).** Every standalone game publishes
   `{ name, xp, stars, gamesPlayed, bestScore, updatedAt }` under `<game>_profile`.
   The hub aggregates XP/stars from those keys in addition to the three world profiles.
   XP scale matches the engine economy (a strong run ≈ one lesson: 15–30 XP).
2. **FlipMatch as the template (this pass).** Points scoring with streak bonuses and a
   board-clear bonus (was: score = pair count), a new **Word Match** mode (match each
   picture card to its word card — memory + early literacy), stars per run, and XP
   written to `flipmatch_profile` at game over.
3. **Phase 2.** Roll the contract to AbcBuzz and SentenceQuest; deepen PatternPop and
   RhymeTime (more rounds, difficulty ramp, the same scoring/XP treatment).
4. **Phase 3.** Character art pass (player kid: backpack clearly visible — see
   CHARACTER-BIBLE notes), engine de-duplication, and accounts/cloud saves when the
   hub is ready to leave localStorage behind.
